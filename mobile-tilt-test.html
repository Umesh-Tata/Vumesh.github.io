Testing Instructions

For Mobile Devices:

  1. Open this page on a mobile device (phone or tablet)
  2. Tap anywhere on the page to enable motion sensors
  3. Grant permission when prompted (iOS Safari)
  4. Tilt your device left/right and forward/backward
  5. Watch the circle above tilt in response to device movement

For Desktop:

  1. Open browser developer tools (F12)
  2. Enable device simulation (mobile view)
  3. Use the device orientation controls in dev tools
  4. Or use the device orientation API in console

Console Testing

Open browser console and run:

// Simulate device orientation (for testing)
window.dispatchEvent(new DeviceOrientationEvent('deviceorientation', {
  beta: 45, // Front-to-back tilt
  gamma: 0 // Left-to-right tilt
}));
